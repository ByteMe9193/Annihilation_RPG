# Aniquilação

Aplicativo companion para o RPG de mesa **Aniquilação**, um projeto pessoal de sci-fi/biohorror desenvolvido principalmente por diversão e para explorar recursos e tecnologias por conta própria.

A ideia é criar uma experiência complementar à mesa, permitindo coisas como fichas de personagem, cartas, memórias, inventário e interações controladas pelo Mestre.

## Tecnologias

- React Native
- Expo
- Expo Router
- TypeScript
- Firebase / Cloud Firestore
- React Native Reanimated
- React Native Paper

## Sobre o projeto

Este projeto não tem finalidade comercial. Ele está sendo desenvolvido como um projeto pessoal para:

- Desenvolver e experimentar com React Native e Expo;
- Aprender e explorar o Firebase e o Firestore;
- Experimentar sincronização de dados em tempo real;
- Criar interfaces e experiências interativas para RPG;
- Explorar desenvolvimento de aplicativos na prática.

O aplicativo é desenvolvido especificamente para o universo de **Aniquilação** e acompanha a campanha de RPG de mesa.

> Projeto feito por diversão, aprendizado e curiosidade.
